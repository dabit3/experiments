# Design-pass captures

Web release build, 1280x800 CSS px, light theme, captured with Playwright after
the HUD / results / title / garage redesign. `captions.json` maps each file to
the caption used in the edited review video (`test/make_review_video.py
--design`). Layout follows publicly documented kart-racer screen conventions
(item slot top-left, lap/clock top-right, large place numeral + speedo
bottom-left, minimap bottom-right, start lights, results table with +pts and
running total) rendered with original Nitro Tots art; no proprietary assets.
