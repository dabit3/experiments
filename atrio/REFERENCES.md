# Reference audit — Archicad 28

Inspected 15 September 2026. Single reference version: Archicad 28, International.

## Accessible source observations

1. [Official Info Box documentation](https://help.graphisoft.com/AC/28/INT/_AC28_Help/020_Configuration/020_Configuration-22.htm)
   and [WallInfoBox.png](https://help.graphisoft.com/AC/28/INT/_AC28_Help/020_Configuration/WallInfoBox.png).
   The source image is 921 × 51 px. A pale grey horizontal strip contains
   narrow vertical separators, tiny header labels above compact white controls,
   a selected tool panel, layer field, geometry method icons and reference line.
   Info Box stays visible, changes with selected elements, and displays
   Selected/Editable counts. Atrio uses this hierarchy in a 65 px strip for
   legibility on browser desktops.
2. [Official Navigator documentation](https://help.graphisoft.com/AC/28/INT/_AC28_Help/030_Interaction/030_Interaction-3.htm)
   and [NavigatorPalette00030.png](https://help.graphisoft.com/AC/28/INT/_AC28_Help/030_Interaction/NavigatorPalette00030.png).
   Image: 235 × 531 px. Four map icons at top; 23 px search field; indented
   tree with Stories, Sections, Elevations and 3D; blue selected-map state,
   grey selected row; Properties section at bottom. Atrio's Navigator is
   250 px wide, uses 24 px tree rows, and retains these folder relationships.
   Unsupported documentation maps are visibly disabled.
3. [Archicad 28 work environment changes](https://help.graphisoft.com/AC/28/INT/_AC28_Help/005_NewFeatures/005_NewFeatures-22.htm)
   and [RearrangedToolbar.png](https://help.graphisoft.com/AC/28/INT/_AC28_Help/005_NewFeatures/RearrangedToolbar.png).
   Image: 1322 × 114 px. White title/menu rows, grey toolbar, thin separators,
   fine dark outlined icons. Labelled Guides, Grids, Trace, Measure, Group,
   3D Cutaway. Atrio uses 24/26/39 px title, menu, and toolbar rows, 17 px
   outlined icons, blue selection fills, and only supported toolbar actions.
4. [Shoegnome's Archicad 28 workspace article](https://shoegnome.com/2024/10/28/shoegnome-work-environment-for-archicad-28/)
   and [workspace image](https://shoegnome.com/wp-content/uploads/2024/10/WE-28-Cover-Image.jpg).
   1568 × 1045 px image confirms a very narrow tab strip directly beneath
   toolbar, a large uninterrupted model view, centered filename, and restrained
   grey desktop chrome. This supplementary image is a customized macOS
   workspace; Atrio follows the official International palette arrangement.

## Application mapping

- Route `/`: all local workspace states; model and plan tabs share elements.
- Toolbox: select, wall, slab, door; other native object families explicitly disabled.
- Navigator: story navigation and axonometric/perspective views; view-label search.
- Quick Options: layer combination, model appearance, scale, and sun preset.
- Local model: editable building primitives, dimensional units in metres,
  linked wall openings, transactions, undo/redo, strict project import/export.
- Reference imagery is kept in ignored audit evidence only, not shipped as app
  content. All architectural geometry, plants, furniture and SVG icons in the
  viewport are original procedural content. Lucide icons are ISC licensed.

## Evidence boundaries

The native commercial application and its engine were not available for
interactive comparison. The source documentation and screenshots were actually
opened and inspected; no native license or account was sought. Screenshot
measurements above are observed image dimensions; Atrio layout dimensions are
implementation choices for the requested browser V1, not pixel-diff scores.

The clone-this skill's reference inventory and iterative audit process is used.
Its zero-difference native parity gate is **not satisfied or claimed**. The user's
explicit browser V1 scope takes precedence over complete commercial parity.
No matched-fixture source render or zero-pixel comparison is fabricated.
