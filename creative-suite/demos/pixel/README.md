# Pixel / After hours

Native macOS UI test artifact. `demo.py` drives the real packaged Pixel app
through CGEvent mouse/keyboard events and Accessibility field selection.
`Native.swift` also provides the AppKit sidecar, which reads the current
function's actual `inspect.getsource()` text and checked assertion results.
Only the input landscape is generated by `Seed.swift`; no finished document
or app state is injected. Project JSON is read only after the real Save command.

## Requirements

- macOS 14+, Xcode/Swift, Python 3, native graphical session.
- Accessibility and Screen Recording permission for the automation host.
- A **1600 × 1200, 1×** display. The harness deliberately fixes Pixel at
  1120 × 1140 on the left and the 472-pixel AppKit sidecar on the right.
- `ffmpeg` / `ffprobe` for capture and inspection; no browser or web service.
- A fresh output directory for every run; never reuse existing export names.

## Package and prepare

Wait for other SwiftPM builds/audits to finish. From `creative-suite/`:

```bash
export DEVIN_DIST="$HOME/PixelDemo-build-$(date +%Y%m%d-%H%M%S)"
bash scripts/build-apps.sh debug
open -n "$DEVIN_DIST/Devin Pixel.app"

export PIXEL_DEMO_OUT="$HOME/PixelDemo-run-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$PIXEL_DEMO_OUT/inputs"
swiftc demos/pixel/Native.swift -o "$PIXEL_DEMO_OUT/native"
swiftc demos/pixel/Seed.swift -o "$PIXEL_DEMO_OUT/seed"
"$PIXEL_DEMO_OUT/seed" "$PIXEL_DEMO_OUT/inputs/After Hours.png"
"$PIXEL_DEMO_OUT/native" frame
"$PIXEL_DEMO_OUT/native" viewer "$PIXEL_DEMO_OUT/live.json"
```

Keep that viewer process running. Do not overwrite its binary. If rerunning,
close the previous Pixel instance normally and reopen the same packaged app;
avoid launching competing Pixel processes.

## Run and record

Start a real-time full-display capture with the pointer visible, then run in
another shell:

```bash
set -o pipefail
PIXEL_DEMO_PACE=0.7 python3 -u demos/pixel/demo.py \
  2>&1 | tee "$PIXEL_DEMO_OUT/run.log"
```

`PIXEL_DEMO_INTERACTIVE=1` optionally waits for Return before each step.
The default is one continuous automated flow. `PIXEL_DEMO_PACE` only controls
UI wait durations, not video playback speed or fabricated animation.

If capturing without Devin's recording tool, discover the screen input with
`ffmpeg -f avfoundation -list_devices true -i ""`, then use its screen device:

```bash
ffmpeg -f avfoundation -framerate 30 -capture_cursor 1 \
  -i "Capture screen 0:none" -c:v libx264 -preset veryfast -crf 18 \
  -pix_fmt yuv420p "$PIXEL_DEMO_OUT/After-Hours-native.mp4"
```

Stop capture with `q` only after the final PASSED reveal. Inspect the actual
recording duration and sampled frames. Devin's auto-edited movie may accelerate
native activity excessively: prefer a real-time MP4 remux of **all** raw screen
segments, in order, without cuts or speed changes.

## Checks and outputs

The runner checks one starting image at 900 × 1100, nonzero exposure,
marquee dimensions within one pixel of 680 × 515, a changed paint image,
exact whole-layer Undo/Redo restoration, Screen blend, exact editable title
and signature strings, four saved layers, PNG dimensions, and reopened
project-data equality. Inspect screenshots/video separately for visible UI
and typography; model checks alone do not prove appearance.

Outputs include `After Hours.devin`, `After Hours.png`, `stroke-held.png`
(captured before mouse-up), `selection.png`, `final-artwork.png`,
`final-desktop.png`, and `run.log`. The app remains open with the final artwork.

## Native interaction notes

- The first AXScrollArea is the document tab strip, not the canvas. The runner
  selects the large canvas scroll region and combines its center with the
  visible zoom percentage. Its coordinate contract is intentionally fixed.
- Pixel's app-level Cmd+A maps to Select All and can interfere with native
  text-field selection. The harness selects only the field's AXSelectedTextRange,
  then types through CGEvent. Native Go To Folder receives the directory;
  Save As receives the filename only.
- Native open panels are moved into Pixel's left-hand area so that the live
  source sidecar stays unobstructed.
- Avoid double spaces in native text input: macOS text replacement may turn
  them into a period. Text frames must be tall enough for the configured leading.
- Coverage is this focused artwork story, not Photoshop parity or every tool.
