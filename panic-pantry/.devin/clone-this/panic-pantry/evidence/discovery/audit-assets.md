# Audit: assets

All assets are original or permissively licensed; nothing was copied from
the source title.

| Asset class | Provenance | Where | Verified |
| --- | --- | --- | --- |
| Typography | Nunito, JetBrains Mono (SIL OFL 1.1) | `app/pubspec.yaml` fonts | build log (`evidence/tests/build.log`); rendered in every screenshot |
| UI icons | Material Symbols rounded (Apache 2.0) | `Icons.*_rounded` | `flutter analyze`; screenshots |
| Sprites: tiles, chefs, ingredients, pots, plates, fire, particles | procedural CoreGraphics-free Flutter `Canvas` drawing | `app/lib/game/sprites.dart`, `particles.dart` | E2E gameplay screenshots |
| Launcher icons (iOS, Android, macOS, web/favicon) + web manifest | generated by `app/tool/make_icons.swift` (original pot / steam / checker mark) | `app/ios/Runner/Assets.xcassets`, `app/android/app/src/main/res/mipmap-*`, `app/macos/Runner/Assets.xcassets`, `app/web/icons`, `app/web/favicon.png` | `audit-rebrand.md`; `swiftc -parse` in `quality.log` |
| Strings: product name, dish/chef/level names, copy | original | `core/lib/src/levels.dart`, `items.dart`, screens | `audit-rebrand.md` grep |
| Audio | none shipped (documented limitation) | README "Known limitations" | - |
| Home key art | generated specifically for Panic Pantry from an original toy-diorama kitchen prompt, no reference-game image | `app/assets/arcade-kitchen.png`, bundled by `app/pubspec.yaml` | clean builds, home screenshots and normalized comparisons |

No binary asset in the repository is derived from Overcooked. Artwork binaries
are the generated launcher icons and original home illustration; bundled fonts
retain their licenses.
