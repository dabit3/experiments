# Rebrand audit

The product is **Brickfolk** everywhere a user can see it:
- app name, bundle ids (`dev.brickfolk.*`), window title, wordmark, app icons
  (`tool/make_icons.py`);
- currency is **pips**, experiences are **places**;
- experiences: Skyline Obby, Brick Tycoon, Freeze Tag Arena;
- badges, shop items and bots have original names.

`evidence/quality/rebrand-scan.txt` lists every occurrence of the source brand
terms in shipped code and docs; the only hits are the honest reference-boundary
statements in `README.md`, `PROTOCOL.md` and this run's notes. No source logos,
characters, sounds or trademarks are present (see assets audit).
